# 2026-11-03

## 网易云歌单排序器：新增「搜专辑」+ 性能与线程修复（commit 5f6b3a5）

- 新增 `ui/search_dialog.py`：统一搜索弹窗，两模式
  - 从我的歌单筛选：歌手/专辑/歌曲名多字段 + `-` 排除关键词；结果按专辑分组，可取消勾选
  - 全网搜专辑：`search album` → 专辑列表勾选 → `album tracks` 收整张专辑
- 新增 `utils/match.py`：NFKC + 去空白 + casefold 归一化后包含匹配，`group_by_album`
- `core/ncm_client`：`ncm_search_tracks_in_playlists`（每歌单只抓一次，旧实现抓两遍）、
  `ncm_search_albums`、`ncm_get_album_tracks`、`ncm_collect_album_tracks`、`ncm_fill_publish_time`
- 关键 bug：后台线程里 `QTimer.singleShot` 不触发（线程无事件循环），导致加载完表格空白、
  进度条不动。新增 `ui/ui_thread.post()`（pyqtSignal 排队回 GUI 线程）并替换所有调用点。
- 发行时间改为按需加载 + `TEMP/ncm_album_publish_cache.json` 缓存：大歌单（4374 首 / 3523 张专辑）
  原来每次加载都要逐张 album get（十几分钟），现在默认不拉，排序用到时才询问。
- 实测：`逆転裁判` 全网搜到 39 张专辑；某 4374 首歌单按专辑筛出 103 首 / 12 张专辑。
- 打包 spec 无需改动（PyInstaller 自动分析导入）。

## 打包（commit ea87e56）

- `pyinstaller 网易云歌单排序器2.spec --noconfirm` → `dist/网易云歌单排序器2/`
  必须手工补 `cp dist/ncm-cli-bundle.exe "dist/网易云歌单排序器2/ncm-cli.exe"`
- **打包前先备份 exe 目录的 `config.json`**（含 app_id/private_key），打完再还原
- 两个打包专属 bug（已修）：
  1. `_get_bundled_ncm_cli` 原来只看 `_internal` 同级，找不到 exe 根目录的 ncm-cli.exe
     → 回退系统 npm；现已检查 `_MEIPASS` / exe 同级 / exe 同级 `_internal`
  2. 调 ncm-cli 时整个替换 env 丢 `SYSTEMROOT`，Node 报 `NetworkError: 网络连接异常`
     → 改为 `_ncm_env()` 合并系统环境
- 发布 zip：`dist/网易云歌单排序器2.zip`（65MB，根目录名 `网易云歌单排序器2/`，**不含 config.json**）
- 打包实测：用内置 ncm-cli.exe、登录检查 OK、30 个歌单、曲目 11 行正常渲染
- 注意：PyInstaller 的 COLLECT 会自己删输出目录，后台执行时会被 safe-delete 拦
  （224 项 > 阈值 50），需前台先 `rm -rf` 输出目录再构建


## UI 按网易云客户端风格重做（commit d3558cd / f21cc26）

- 新增 `ui/theme.py`：配色常量 + 全局 QSS + `apply_theme(app)` + `apply_dark_title_bar()` + `app_icon()`
  - 主色 #EC4141；内容区 #1E1E1E、侧栏 #191919、卡片 #252525、输入框 #2A2A2A
  - QSS 用的对勾/箭头图标在运行时用 QPainter 画到 `TEMP/ncm_sort_theme/`，不依赖外部资源
  - 深色标题栏用 `DwmSetWindowAttribute(hwnd, 20/19, 1)`
- 样式靠动态属性：`setProperty("variant", "primary|ghost|round|search|h1|section|sub|weak")`，
  运行中改属性后必须 `_repolish(widget)`
- 主窗口重构：`_build_sidebar()` + `_build_content()`，左侧栏/顶栏搜索/歌单头部/排序卡片/曲目表/底部状态条
- 表格：`setWordWrap(False)` + ElideRight + 行高 38 + 无网格；ID 列默认隐藏（侧栏「显示歌曲 ID」开关），
  hover 歌曲名有加密 ID tooltip；去掉了 `resizeRowsToContents()`（大歌单很慢）
- 各弹窗（搜索/配置/登录/AI）统一主题，去掉原绿/紫/青色内联样式；配置弹窗重排为右下角按钮行
- 踩坑：PyQt6 里 QSS `QWidget{background:transparent}` 会让子控件透明，需要给 `#central/#sidebar/#card` 单独设底色；
  QListWidget::item 的 padding 会让 item 高度异常，改用 `min-height` + 水平 padding
- 验收方式：真实窗口 `w.grab()` / `screen.grabWindow(0)` 裁剪截图，用 ViewImage 看图迭代
